## 阻塞 / 风险

- **Bash 安全分类器会整体不可用（第 5 次，本轮）**：非只读命令（`npm run *`、`npx tsx`、`git`）全部被挡，
  只读命令（`grep`/`sed`/`cat`）可过。**表现是"命令没跑"而不是"命令失败"** ——
  别把它当成代码出问题。绕法：请用户用 `!` 前缀自己执行，输出会回到会话里。
- **真实 API 有费用且依赖网络**：四轮共约 130 次调用。`docs.typesafe.ai` 有过被网络策略拦下的记录，
  所以版本固定问题至今没查实。

  （Ray ID `a3f696b959ae15e5`，出口 IP `154.21.95.7`）。任何含 SQL/HTML 样式的用户输入都可能被边缘拦掉 ——
  这条风险**依然成立**（F-10 只保证它被受控地表达成 502/50003，不代表上游会收下输入）。
- **`TYPESAFE_MODEL` 是否可填具体版本号 —— 未确认。** 代码刻意不硬编码版本，

- **同仓库双 Agent 并发**：TA 与 DA 可能同时碰 `app.ts` / 共享服务，规则见协议 §3。
- **`app.ts` 的兜底分支也回显 `error.message`**（同一类泄露，另一个面）：本轮**没动它** ——

## 给 DA（平台开发 Agent）的请求

- **⚠️ 错误契约变了（F-10，本轮）**：端点遇到**上游故障**（超时/429/5xx/边缘拦截）或**未配置 key** 时，
  返回 **HTTP 502 + `code 50003`**，响应体无 `data` 包装：

  ```json
  { "code": 50003, "message": "解析服务暂时不可用, 请稍后重试", "details": [] }
  ```

  两条文案：`解析服务暂时不可用, 请稍后重试`（上游故障）/ `解析服务未配置, 请联系管理员`（缺 key）。
  **前端不要把 502/50003 当"指令非法"提示** —— 那与用户输入无关，应提示"稍后重试"。
  分支请认 `code`（`50003` 稳定），不要认文案。
- **端点响应面已有加法（已提交）**：`data.meta` 多了可选字段 `judgments`
  （`{intent_actionable, mentions_timing, mentions_multiple, target_property_confidence}`）。
  四个原始置信度原样摊开 —— 顶层 `confidence` 是**重载**的（护栏命中时装的是"触发护栏那个问题的
  置信度"，正常路径装的是属性置信度），读表时分不清谁是谁。前端如果要用，直接读 `judgments`，
  不要从 `confidence` 猜。**未调用模型就短路的路径没有这个字段**（如"无可写属性"），前端要判空。
- 若要**接前端**：先读协议 §6 的不变量，尤其两条 ——
  ① `proposed` 只能是对象或 `null`；
  ② **`needs_clarification: true` 不是错误**，要把 `hint` 展示给人看（"请明确给出数字"这类是可操作提示），
  不要当异常弹窗。
- 保持 `app.ts` 里那条路由注册的正则形态 `:action(command:parse)`，理由见协议 §6 第 5 条。
- 前端**不要**直连 TypeSafe：key 在 `backend/.env`，前端只调本端点。
- 这台开发库的设备被我用作用例表夹具（只读，没写任何数据）；如果你要删 `prod-a1b2c3d4` 下的设备，
  知会一声，用例表会需要换设备重标阈值。
